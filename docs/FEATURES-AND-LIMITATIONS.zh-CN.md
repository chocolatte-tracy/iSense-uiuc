# iSense：功能与限制

## 当前功能

面向 UIUC 校园步行的移动优先 PWA，提供 Map、Preferences、Routes、Reports 四个标签。

- **地点与路线：** 校园地点、Google Places (New) 搜索、选定地点坐标及当前定位；
  使用现有 Google Routes 后端获取步行候选路线、完整几何、距离和精确时长。
  可以对比、手动选路并交接给 Google Maps 导航。仍保留清楚标注的演示路线。
- **独立偏好：** 噪音、人群、日照、步行时间的重要性合计 100%，可锁定比例；
  噪音、人群、日照分别设置 Low/Medium/High 接受程度，两种设置不是同一个概念。
  额外步行时间以输入分钟数限制，基准是当前最短路线，不是绝对总步行时长。
- **推荐与解释：** 保留加权代价、接受程度罚则、硬性步行上限和确定性平局处理。
  修改偏好本地重排，不再次请求 Google 路线；详情显示评分来源、未知程度及优缺点。
- **自动日照：** 对真实 Google 完整路线，根据精确步行时长及出发时间，
  在浏览器后台使用历史 DSM/DTM 与太阳位置进行预测。完整模型支持的曝光百分比
  作为实验性日照输入参与排名。展示比例、分钟数、覆盖率及限制。
  路径、时长、出发时间改变即重算；手工研究导入/导出仍独立保留。
- **共享社区反馈：** 带地点、观测时间与主观环境反馈，独立于推荐评分，
  不把单条未经验证的上报当作客观事实或直接改写路线分数。
- **PWA：** 支持添加到主屏幕、独立窗口、安全区域布局、安装帮助及更新提示。
  偏好与锁定状态保存在本机；离线支持主要是静态应用界面。
- **服务端安全：** Routes 密钥不进入浏览器；保留匿名公共模式、地理输入校验、
  每客户端限速、持久化应用日额度、保守费用预留和紧急关闭开关。

## 主要限制

1. **不是实时环境监测。** 未建立校园全域、实时、可用于整条路线评分的噪音和人群数据。
   极小区域的噪音实测不能扩展为全校情况；原始 dB(A) 不等于任意 0–100 舒适度指数。
   缺失、演示、模型估计与真实观测必须区分。Melbourne 模型和 UIUC 月度计数不代表当前拥挤度。
2. **日照仍属实验。** 地形来自 2019–2020 年冬季，约 1.2 km×1.2 km。
   树冠、建筑与当前季节可能不同；只估计潜在直射日照，不预测云、UV、温度、热舒适度或安全。
   模型覆盖率不等于准确率。低太阳高度、边界与缺失地形可能产生未知。
   夜间不是树荫。预测协议仍保留未经现场校准的标识。
3. **舒适度规则未科学校准。** 接受程度阈值与权重公式是原型假设，
   不是医学标准；分数低不保证安静、舒适、无障碍或安全。
   未知数据采用保守处理，不能解读为实际测得的高噪音/高拥挤度。
4. **受 Google 配置、联网与预算限制。** API 开关、密钥授权、服务启用、额度、
   费用预留或网络错误会限制查地点/查路线。限额和预留不是 Google 实际账单的硬性美元封顶。
   首次自动预测还需读取 App Storage 的公开地形文件，不保证完全离线可用。
5. **导航不是逐向引导引擎。** App 交接给 Google Maps；Google 可能忽略部分 waypoints
   或重新计算路径，因此不能保证实际走的路径仍与 app 中的预测路径完全一致。
6. **社区反馈主观且稀疏。** 服务端共享存储与限速不等于内容已经验证，
   没有把其自动训练成实时人群或噪音模型。
7. **PWA 不等于原生应用。** 不提供完整原生后台导航能力。
   浏览器、系统、安装状态和安全区域实现可能不同，实体设备仍需验收。

## 本次验证及发布边界

- 166 项 Node 离线检查通过；Python 28 项通过，2 项外地人流实验因未交接缓存/输出跳过。
- 类型检查、构建、PWA 检查通过。
- 390×844 浏览器用合成路线验证真实 Worker、日照/时间权重切换、硬性时间上限、
  路径与时长变化重算、覆盖不足与资源失败回退。Google 接口被模拟或拦截。
- 以上不代表本轮测试了真实付费 Google 请求、实体手机、生产部署或现场准确度。
- GitHub 上传与 Replit 发布是独立步骤；上传代码不会自动更新公开网站。

更多日照模型、验证及 App Storage 发布说明见 [AUTOMATIC-SUNLIGHT.md](AUTOMATIC-SUNLIGHT.md)。
