# iSense：地点输入与简化界面

## 当前地点搜索逻辑

现有集成使用 Places API (New)，由生产后端的
`GOOGLE_PLACES_API_ENABLED === "true"` 和浏览器密钥共同控制。
本次生产检查确认 Places 已启用，并按团队授权执行了仅一次 Main Library
Text Search，返回 HTTP 200 和有效的校内坐标；没有执行 Routes 请求。
这不是完整 Autocomplete → Place Details 流程的实机测试。

- Destination / Starting at 现在是可输入、可清空的搜索框。
- 空白或已选字段获得焦点时显示校内快捷建议；支持方向键、Enter、Escape 和触摸选择。
- 离线快捷建议保留 Main Quad、Grainger Engineering Library 的团队研究坐标。
- Main Library 不补造固定坐标：Places 可用时使用真实 Google 建议，并在选择后取得、
  验证 Place ID 和坐标。不可用时只显示明确的离线不可用提示。
- 任意文字可以输入，但 **必须选择具体建议并验证坐标后才能确认地点**。
  单次诊断返回的 Google 坐标没有硬编码成长期离线数据。
- 不做免费文本到坐标的猜测，也不将未经选择的文字发送给路线服务器。
- 配置读取显式使用 `cache: "no-store"`；回到前台、恢复网络或从页面缓存返回时
  重新读取应用配置。此检查不发送 Google 请求，也不重置路线、偏好或起终点。
- Service Worker 只缓存静态界面，不缓存 `/api/maps/config` 或 Google 响应。
  本次前端修正需重新发布；旧 PWA 应采用已有更新提示或重新打开页面。

## 首页怎么用

1. 选择目的地和起点；或点 **Use my location** 才请求浏览器定位权限。
2. 点 **Swap** 可交换起终点；方向改变会清除旧结果，不会把已研究路线冒充成反方向路线。
3. 点 **Find routes**：
   - 当前未开启实时路由时，Main Quad → Grainger 使用现有研究 DEMO。
   - 其他起终点不会生成假路线，会说明实时服务尚不可用。
   - 公开路由启用且服务端安全配置有效后，仍调用原有 `/api/walking-routes`，
     传递已选择的 `{lat, lng}` 对象，不要求访客输入团队访问码。
4. 先看一个推荐，再按需展开 **Compare routes**、感官详情和证据。
5. 导航交接仍使用每条路自己的 Google Maps URL/waypoints；Google 可能重新计算，不保证完全保留路径。

## 偏好与功能保留

- **Preferences** 默认折叠；Balanced、Quieter、Less Crowded、Fastest 是用户明确点击才应用的权重预设。
- 预设不修改接受阈值、额外步行限制或锁定权重；有锁时分配剩余未锁权重，可能不是预设的完整比例。
- Customize preferences 保留四个重要性滑块、100% 总和、锁定、Reset、接受设置及各分段说明、数字输入的 Maximum Extra Walking Time。
- 打开、关闭面板不重置当前值；评分仍由原有规则算法在本地运行，不重新请求 Google 路线。
- 数据导入、来源/覆盖说明、实时服务状态、团队访问码在 Research / routing settings 中。
- 安装帮助可由底部 Install 打开；PWA 配置、图标、静态缓存边界不变。

## 定位、安全与过期结果

- 浏览器提供的定位值保留精度信息，只用于当前标签页；不写入离线缓存或本地持久存储。
- 只有明确点击实时 Find routes 才可能把坐标发送到原有路由服务。
- 拒绝、超时、不支持、过于粗略和区域外定位均提示手动选择；迟到的定位回调不能覆盖后续输入或交换。
- 初始可配置 UIUC 服务区域：纬度 **40.08–40.135**、经度 **−88.255–−88.205**。这是产品输入限制，不是官方步行安全边界，也不是噪音、人群或树木数据的覆盖范围。
- 每次修改起终点立即中止旧请求，并使旧结果失效；返回顺序不会使旧路线重新出现。
- 断网中止未完成的请求，但不把内存中已经取得的真实路线替换成另一条 DEMO；重载后不恢复私人路线数据。

## 后续启用真实地址搜索

需要团队确认 Google Cloud 项目已启用 **Places API (New)**，浏览器密钥同时允许 **Maps JavaScript API** 与 **Places API (New)**，并保持 HTTP referrer 限制。

此配置不等于免费或自动授权。后续真实 Places 查询、地点详情及实时 Routes 测试分别需要明确许可。无需提供或暴露服务器 Routes 密钥。
